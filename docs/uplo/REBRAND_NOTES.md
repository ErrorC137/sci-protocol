# SCI Protocol → UPLO: rebrand notes

The rebrand changes **presentation, not internals**. Everything a user sees says UPLO; every identifier that
code, contracts, stored data or deployments depend on keeps its SCI name, so nothing breaks.

## Renamed (user-facing)

| Where | Was | Now |
|---|---|---|
| Page title / metadata / Open Graph | `SCI Protocol` | `UPLO · Today's Capital. Tomorrow's Breakthroughs.` (+ `%s · UPLO` template) |
| Nav / sidebar / footer brand | "SCI" badge + "SCI Protocol" | UPLO logo component (plain-text placeholder until the PNGs exist, see below) |
| Wallet connect app name (`lib/chain.ts` `appName`) | `SCI Protocol` | `UPLO` |
| Application attestation line (`/apply/[id]`) | "SCI Protocol will not submit it." | "UPLO will not submit it." |
| Exported copy-paste pack header (`apps/api/app/forms/fill.py`) | "Generated by SCI Protocol…", "SCI Protocol never submits…" | "Generated by UPLO…", "UPLO never submits…" |
| API docs title (`apps/api/app/main.py`) | `SCI Protocol API` | `UPLO API` |
| ERC-1155 token metadata name (`/chain/fractions/{id}.json`) | `SCI Fraction - Project #n` | `UPLO Fraction - Project #n` |
| Vault error text | "Not an SCI vault blob" | "Not a vault blob" |
| Render services (`render.yaml`) | `sci-protocol-api`, `sci-protocol-ingest`, disk `sci-data` | `uplo-api` (cron + disk removed for the free plan) |

## Deliberately NOT renamed

| What | Why |
|---|---|
| Contracts (`SCIFraction`, `ProjectRegistry`, …) and their ABIs | Renaming means redeploying; the brief forbids redeploying for branding |
| Workspace packages `@sci/web`, `@sci/shared` | Internal import paths; no user ever sees them |
| Env vars `SCI_LLM_MODEL`, `SCI_LLM_TIMEOUT`, `SCI_EXPLAIN_TOP_K` | Existing deployments and docs rely on them |
| Logger name `sci`, API routes | Internal / would break clients |
| Metadata schema ids `sci-protocol/project-metadata@1`, `…/milestone@1`, `…/evidence@1`, `…/rejection@1` | Pinned on IPFS and referenced on-chain; changing them orphans existing records |
| Vault signing message `"SCI Protocol vault key v1 …"` and blob magic `SCIV1` (`apps/web/lib/vault.ts`) | The encryption key is **derived from that exact message**; changing it would make every previously sealed vault entry undecryptable. Users do see this text in their wallet's signature prompt - an accepted trade-off |
| Test wallet name "SCI Test Wallet" in `scripts/e2e/smoke.py` | Test fixture only |
| `README.md`, `docs/DEPLOY.md`, `DEMO_SCRIPT.md` product name | Developer docs for the underlying codebase; `DEMO_SCRIPT.md` becomes the UPLO pitch in Phase 5 |

## Design system (Phase 2)

- Tokens in `apps/web/tailwind.config.ts` + CSS variables in `app/globals.css`: `lime` #D7EB79, `charcoal` #1E2320,
  `copper` #B57856, `limestone` #EDE8DD, `sage` #A7B8A1, `neutral` #D9D9D6, plus `error` #B42318 for destructive
  actions. Extra shades exist for hover states and for AA-contrast text (`lime-700`/`-800`, `copper-700`,
  `charcoal-muted`). The old `brand` / `ink` palettes are gone.
- Fonts via `next/font/google`: Space Grotesk (`font-display`, headings and figures), Inter (`font-sans`), Noto Sans
  Thai in every stack.
- Components (`components/ui.tsx`): Chip tones are now semantic - `neutral`, `positive`, `caution`, `danger`,
  `info`, `dark` (replacing slate/green/amber/red/blue/violet) - plus `StatusChip` (Verified / In Progress /
  Completed). Card tones `light` / `dark` / `danger` / `positive`. Button `primary` (lime, charcoal text),
  `secondary` (charcoal outline), `dark`, `danger`, `ghost`, optional `arrow`. `IconButton` (round, arrow).
- App pages live in the `app/(app)` route group (URLs unchanged) and share `AppShell`: charcoal sidebar with the
  active item in lime, restyled `WalletButton` (RainbowKit `ConnectButton.Custom`, label stays "Connect Wallet").
  `/` uses `SiteNav` + `SiteFooter`.
- Logic is unchanged. The only behavioural edits were string renames above.

## Logo

The kit shipped **no logo files**. `components/Logo.tsx` renders a plain-text "UPLO" placeholder
(`TODO(logo)`), and the favicon (`app/icon.tsx`) / social card (`app/opengraph-image.tsx`) use neutral
placeholders. Drop the official PNGs into `apps/web/public/brand/` (see the README there) and flip
`LOGO_FILES_PRESENT`.
